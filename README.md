# When Status Ends, Identity Does Not

A Grade 11 Ontario English project about the second-generation cut-off in Indian Status registration.

## Files

- `index.html` — cinematic home experience
- `how-rule-works.html` — section 6 comparison and transmission simulator
- `what-formula-misses.html` — identity, family, and community consequences
- `law-now.html` — 1985 to 2026 legal timeline
- `works-cited.html` — MLA 9 Works Cited
- `assets/style.css` — responsive visual system
- `assets/world.js` — shared canvas world, particles, forest, river, birds, stars, cursor physics
- `assets/app.js` — controls, sound, simulator, accessibility

## GitHub Pages

This folder is ready to deploy as a static GitHub Pages site.

1. Put these files at the root of the `MLA` repository.
2. Push to `main`.
3. In GitHub, open **Settings → Pages**.
4. Deploy from GitHub Actions or from the `main` branch root.

A Pages workflow is included in `.github/workflows/pages.yml`.

## Accessibility

The site includes keyboard navigation, visible focus styles, reduced-motion support, a manual motion toggle, a sound toggle with no autoplay, semantic headings, screen-reader explanations for the simulator, responsive layouts, and no essential information communicated by colour alone.
